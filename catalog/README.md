# Catalog

`catalog.json` is generated for every release by `scripts/build-catalog-release.mjs` after all first-party plugin packages have been signed. `catalog/official-publisher.json` is the committed public trust metadata for Nexus first-party releases; `scripts/check.mjs` derives its Ed25519 key id from `publicKeyPem` and rejects any mismatch.

The production Nexus Host pins the same official publisher key id/public key and may only replace the catalog or mirror URL. During release, `build-catalog-release.mjs` derives the public identity from `NEXUS_AGENT_PLUGIN_SIGNING_KEY_PEM` and fails with `OFFICIAL_PLUGIN_SIGNING_KEY_MISMATCH` unless it exactly matches the committed official publisher metadata. Package entries also publish `sdkVersion` and `nexus.minVersion/maxVersion` so a Host can preflight compatibility before downloading bytes; the signed manifest repeats the compatibility check after verification. Package SHA-256, size, Ed25519 signature, signed file list, target entries, and Skill files are verified again during installation.
