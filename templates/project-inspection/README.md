# Project inspection workflow

This second App has a form and report surface. It reuses `nexus.tools.remote` and explicitly references the installed `nexus.agent` execution policy through its signed dependency range. Assign your own id and signing key, sign with the repository's normal release builder, install the compatible dependencies, and compose this App with its own UI. The Host resolves and freezes the exact execution package identity for each Run.

Grant `plugin.invoke` for package execution, `context.read` for the agent package's discovery tool, and `file.read` for the selected authorized target. Both tools are explicitly selected by the App. Declaring or selecting them grants no permission; missing or revoked grants must cause a Host refusal. The Host independently governs catalog activation and every remote read.

Open the App, select a configured model, and enter an authorized connection ID and absolute project directory. The form creates a Host-managed thread and Run in `ask` mode, restricted to that target. Its submitted task and selected tools use `tool_search` to discover `remote_project_inspect`; the Host remains responsible for current grants, target validation, approval, cancellation and auditing. Use “Refresh report and approvals” while a Run is active to review pending operations. Pending approvals expose the exact Host inspection and version/hash-bound approve/deny commands. Lifecycle updates refresh assistant report pages through the SDK and render as text. Lost command responses are displayed without replay.

Acceptance: inspect a directory containing `package.json`; verify the report lists observed manifest information and existing check/build scripts without running them. Compose the same tool version into `nexus.agent`, then update only the tool package to the tested compatible patch and verify both Apps continue to work. Disable or revoke the dependency and verify a refusal rather than a fabricated report. Real SSH/model/browser acceptance belongs to Host integration; the package test exercises this exact frontend source with SDK fixtures.
